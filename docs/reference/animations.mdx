The shared widget wrapper emits CSS entrance animations. Individual renderers can also emit CSS or SMIL elements such as `<animate>` and `<animateTransform>` inside their SVG markup.

## Animation Types (`AnimationType`)

| ID            | Name        | Description                   | Keyframe Implementation                                      |
| :------------ | :---------- | :---------------------------- | :----------------------------------------------------------- |
| `none`        | None        | Instant static appearance     | No CSS injected                                              |
| `fade-in`     | Fade In     | Smooth opacity transition     | `opacity: 0` $\rightarrow$ `opacity: 1`                      |
| `slide-up`    | Slide Up    | Upward translation reveal     | `transform: translateY(8px)` $\rightarrow$ `translateY(0)`   |
| `slide-down`  | Slide Down  | Downward translation reveal   | `transform: translateY(-8px)` $\rightarrow$ `translateY(0)`  |
| `slide-left`  | Slide Left  | Slide from right to left      | `transform: translateX(12px)` $\rightarrow$ `translateX(0)`  |
| `slide-right` | Slide Right | Slide from left to right      | `transform: translateX(-12px)` $\rightarrow$ `translateX(0)` |
| `zoom-in`     | Zoom In     | Scaled expansion              | `transform: scale(0.9)` $\rightarrow$ `scale(1)`             |
| `zoom-out`    | Zoom Out    | Scaled compression            | `transform: scale(1.1)` $\rightarrow$ `scale(1)`             |
| `flip-x`      | Flip X      | Horizontal 3D flip            | `transform: rotateX(90deg)` $\rightarrow$ `rotateX(0deg)`    |
| `flip-y`      | Flip Y      | Vertical 3D flip              | `transform: rotateY(90deg)` $\rightarrow$ `rotateY(0deg)`    |
| `typewriter`  | Typewriter  | Line-by-line character typing | Cascading `clipPath` reveals                                 |
| `glitch`      | Glitch      | Cyberpunk signal glitch       | Skew and opacity steps                                       |
| `scan-lines`  | Scan Lines  | CRT scan line sweep           | Animated inset clip-path and opacity                         |

The wrapper’s `typewriter` branch applies to `ascii-art`, `ascii-text`, and IDs starting with `terminal-`. Other widgets may have their own typing effects; setting this option alone does not add typing to every renderer.

---

## Easing Functions (`AnimationEasing`)

- `ease`
- `ease-in`
- `ease-out` (Default)
- `ease-in-out`
- `linear`
- `spring` (`cubic-bezier(0.34, 1.56, 0.64, 1)`)

Animation playback depends on the SVG viewer. Editor pointer interactions do not transfer to an embedded README image; see [display limits](/reference/data-sources).
