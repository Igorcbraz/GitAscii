---
title: 'TypeScript Definitions'
description: 'Canonical configuration, rendering, and GitHub-data types'
---

The engine types are internal exports from the GitAscii repository:

```typescript
import type {
  SavedConfiguration,
  WidgetInstance,
  WidgetConfig,
  GlobalStyles,
  RenderOptions,
  NormalizedGitHubData,
} from '@/engine'
```

`@/` resolves to `src/` in this checkout. It is not an npm package name.

| Type                   | Purpose                                                                                        | Source                                                                                                                                     |
| :--------------------- | :--------------------------------------------------------------------------------------------- | :----------------------------------------------------------------------------------------------------------------------------------------- |
| `SavedConfiguration`   | Identity, profile slug, template, widgets, styles and revision metadata.                       | [engine/types.ts](https://github.com/Igorcbraz/GitAscii/blob/f248c939a3ea7810c3d3e331ae904b56a72b998f/src/engine/types.ts)                 |
| `WidgetInstance`       | Instance ID, renderer ID, position, size, config, visibility, lock and layer.                  | Same file.                                                                                                                                 |
| `WidgetConfig`         | Common optional properties plus a string-keyed `unknown` extension map.                        | Same file.                                                                                                                                 |
| `GlobalStyles`         | Canvas and inherited widget styling.                                                           | Same file.                                                                                                                                 |
| `RenderOptions`        | Theme, dimensions and widget selection. Declared font/optimization flags are currently unused. | Same file; see [rendering](/api/rendering).                                                                                                |
| `NormalizedGitHubData` | GitHub user/repositories, language totals, contributions and optional derived fields.          | [github.ts](https://github.com/Igorcbraz/GitAscii/blob/f248c939a3ea7810c3d3e331ae904b56a72b998f/src/features/github/types/github.ts)       |
| `WidgetRendererFn`     | Synchronous function returning SVG fragment markup.                                            | [WidgetRegistry.ts](https://github.com/Igorcbraz/GitAscii/blob/f248c939a3ea7810c3d3e331ae904b56a72b998f/src/engine/core/WidgetRegistry.ts) |

See [configuration](/api/configuration) for the main model and [JSON storage](/api/json) for the distinction between editor exports and published files. TypeScript interfaces are not runtime JSON Schema validators, and an arbitrary key in `WidgetConfig` has no effect unless its renderer reads it.

Optional data fields in the type are not a guarantee that every rendering path supplies them. See [data sources and display limits](/reference/data-sources).
