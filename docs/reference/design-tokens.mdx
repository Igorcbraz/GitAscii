title: 'Design Tokens & Colors'
description: 'Application color and typography tokens, separate from SVG rendering'
---

These tokens describe the web application styles in `src/app/globals.css`. Published SVGs use their saved global styles and renderer output; they do not load the app stylesheet.

## Color Tokens

```css
:root {
  /* Core Canvas & Neutrals */
  --color-void-black: #000000;
  --color-carbon: #060606;
  --color-graphite: #252525;
  --color-onyx: #1f1f1f;
  --color-iron: #313131;
  --color-slate: #3d3d3d;
  --color-fog: #525252;
  --color-ash: #7a7a7a;
  --color-smoke: #8a8a8a;
  --color-pearl: #c5c5c5;
  --color-bone: #e5e5e5;
  --color-chalk: #ffffff;

  /* Signature Accents */
  --color-signal-lime: #c5ff4a;
  --color-olive-depth: #597321;
  --color-moss-shadow: #314013;
}
```

## Typography Hierarchy

| Font Family        | Weights             | Intended Use                                  |
| :----------------- | :------------------ | :-------------------------------------------- |
| **PT Serif**       | `400`, `700`        | Elegant display titles, editorial headings    |
| **Inter Tight**    | `400`, `500`, `600` | Interface text, card titles, status tags      |
| **JetBrains Mono** | `400`, `500`, `600` | Monospace code, metadata, coordinates, labels |

A font-family name in SVG does not guarantee that the image viewer can load the same web font as the editor. See [rendering](/api/rendering).
