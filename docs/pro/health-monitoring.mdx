# Health Monitoring & Badges

The Pro health console at `/pro/health` reflects reported publication runs. The GitHub Action renders configured profiles, inlines permitted external assets, commits the SVGs, and sends an authenticated report to `/api/pro/telemetry`. The report records run duration, status, profile slugs, and failed asset URLs when available.

A health score describes the share of **reported successful publication renders** in the tracked period. An active error can change the displayed status. It is not the uptime of every README image fetch, and it does not measure each visitor's latency. When no runs have been recorded, the console has no measured success rate.

The public health badge can be embedded separately:

```markdown
![GitAscii Profile Health](https://gitascii.com/api/USERNAME/health-badge)
```

The badge summarizes the stored health state and is cached. It is distinct from the analytics badge at `/api/badge/USERNAME` and from the published profile SVG. You can inspect incidents in `/pro/errors` and use the health simulator in `/pro/health` to test the dashboard without waiting for a real workflow failure.
