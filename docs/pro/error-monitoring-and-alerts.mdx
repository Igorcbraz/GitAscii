# Widget Error Monitoring & Alerts

During a v2 refresh, the GitHub Action renders each configured profile and processes external assets. For Pro accounts, it can send failed asset URLs and a run result to GitAscii using GitHub OIDC. The app records an error for the affected profile; the README continues to reference the last published SVG until a successful update.

```mermaid
flowchart LR
  Action[GitHub Action refresh] -->|OIDC report| API[/api/pro/telemetry]
  API --> Store[Health and error records]
  Store --> Console[/pro/errors]
  Store --> Alert[Optional email alert]
```

The `/pro/errors` console shows the reported profile, asset or widget label, error message, occurrence count, and resolution state. The public SVG fetch does not execute widget code, so an external service failing between refreshes is not detected at README view time.

Email alerts require an eligible Pro account and enabled email settings. Repeated alerts for the same widget are suppressed for roughly one hour. You can mark an error resolved in the console or use the simulator to test alert behavior. See [Health Monitoring](/pro/health-monitoring) for the separate publication success signal.
