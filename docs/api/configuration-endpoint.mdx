---
title: 'Read a Configuration'
description: 'GET /api/config/:username/:profileSlug'
---

Returns a saved [SavedConfiguration](/api/configuration). This read is anonymous; published layout JSON is not a secret store.

```bash
curl -i https://gitascii.com/api/config/octocat/default
```

| Parameter     | Location | Meaning                                         |
| :------------ | :------- | :---------------------------------------------- |
| `username`    | Path     | GitHub handle                                   |
| `profileSlug` | Path     | Saved profile slug, such as `default` or `work` |

On success, the body is the configuration itself, without a `config` wrapper. It contains identity, template, widgets, global styles, and metadata. The route prefers GitHub-backed configuration loading; see [storage](/api/json) for fallback responsibilities.

| Status | Body                                                                            |
| :----- | :------------------------------------------------------------------------------ |
| `200`  | `SavedConfiguration` JSON                                                       |
| `400`  | `{"error":"Username is required"}` for a missing username passed to the handler |
| `404`  | `{"error":"Config not found"}`                                                  |
| `500`  | `{"error":"<failure message>"}`                                                 |

Successful responses set `Cache-Control: public, s-maxage=60, stale-while-revalidate=300`. This endpoint does not write configurations or dispatch Actions. Use the editor to publish changes.
