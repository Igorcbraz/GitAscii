Widget ID: `controlplane-monolith`.

The Monolith Strata Index widget formats repositories using Swiss/Internationalist typography principles, featuring stark horizontal strata lines, large index numbers, and high-contrast typography.

These visual meters and connections are decorative; they do not monitor deployments or hardware. See [data sources and display limits](/reference/data-sources).

## Configuration Schema

```typescript
export interface MonolithConfig {
  maxRepos?: number
  accentColor?: string
}
```

---

## Real Code Example

```typescript
import { renderWidgetSvg, WidgetInstance } from '@/engine'

const monolithWidget: WidgetInstance = {
  instanceId: 'monolith_01',

  position: { x: 0, y: 0 },
  size: { width: 800, height: 330 },
  config: {
    accentColor: '#ffffff',

  locked: false,
  visible: true,
  zIndex: 1,

const svgOutput = renderWidgetSvg(monolithWidget, profileData, globalStyles)
```
