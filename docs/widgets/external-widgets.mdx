External cards are fetched during publication and inlined into the final SVG. They do not execute on every README visit. The renderer emits request markers; `processExternalAssets` resolves and sanitizes them before the backend or Action commits the result.

The options below are read by the current GitAscii adapter. They are not a promise that an upstream service accepts every request or exposes private metrics.

| Widget ID             | Selected supported options and defaults                                                                                                                                                                                        |
| :-------------------- | :----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `github-readme-stats` | `statType: 'stats'` (also `top-langs`, `pin`); `theme: 'dark'`; `showIcons: true`; `countPrivate: false`; `includeAllCommits: false`; `hideRank`, `hideBorder`; `repoName`, `layout: 'compact'`, `langsCount: 5`, `hideLangs`. |
| `streak-stats`        | `theme: 'dark'`, `mode: 'daily'`, `dateFormat: 'M j, Y'`, `streakBorderRadius: 4`, `hideBorder: false`.                                                                                                                        |
| `profile-trophy`      | `theme: 'flat'`, `column: 6`, `row: 1`, `noBg: false`, `noFrame: false`. The current `noFrame` adapter adds `margin-w=0`, rather than an upstream `no-frame` parameter.                                                        |
| `contribution-snake`  | `username`, `theme: 'dark'` (or `light`), `branch: 'output'`. Reads an existing snake artifact; see below.                                                                                                                     |
| `metrics-card`        | `template: 'classic'`, `baseSections: 'header,activity,community,repositories'`.                                                                                                                                               |
| `views-counter`       | `color: '00f0ff'`, `style: 'for-the-badge'`, `label: 'PROFILE VIEWS'`, `baseVal: 0`. This is a publication-time snapshot.                                                                                                      |
| `gitfest-lineup`      | `username`, `theme: 'dark'`, `sort: 'stars'`, `order: 'asc'`, `type: 'owner'`, `invertColors`, `hideRepos`. Requires a reachable GitFest service configured for the renderer.                                                  |
| `ghstats`             | `embedType: 'card'` (also `langs`, `mini`, `badge`), `theme: 'default'`, `showIcons`, `showRing`, `hideBorder`, `hideTitle`, `size`, `compactCount`, `hideStats`, `customTitle`, `layout`, `maxLangs`, `badgeStyle`.           |
| `awesome-badge`       | `badgeStyle: 'for-the-badge'`, `badgeColor: 'brightgreen'`, `label: 'Awesome GitHub Profile'`, `logo: 'github'`. A configured badge, not verification of an award.                                                             |
| `custom-image`        | `imageUrl` (aliases `src`, `url`), `targetUrl` (alias `href`), `mode: 'contain'` (or `badge`), `showTitle: false`, `customTitle`.                                                                                              |

Most external cards accept `showTitle` and `customTitle`; their defaults and upstream options differ. See the [adapter source](https://github.com/Igorcbraz/GitAscii/blob/f248c939a3ea7810c3d3e331ae904b56a72b998f/src/features/widgets/renderers/ExternalWidgetsRenderer.ts) for the full request construction. `activity-graph` is not registered in the current widget registry.

## Contribution Snake setup

The widget looks for `github-contribution-grid-snake-dark.svg` or `github-contribution-grid-snake.svg` in the configured branch of `USERNAME/USERNAME`, through the configured CDN endpoint. You need a separate snake-generation workflow or an existing artifact. The V2 GitAscii publisher workflow does not generate those snake files.

If the user's artifact cannot be loaded, the adapter supplies a Platane sample as fallback. A visible snake can therefore be sample content rather than the user's contribution history.

## GitFest configuration

The source uses `NEXT_PUBLIC_GITFEST_URL`, with `http://localhost:3000` as fallback. That fallback does not establish a reachable public GitFest service in GitHub Actions. Availability depends on the configuration incorporated into the executing renderer/bundle; adding a card is not service provisioning.

## Failure and display behavior

A denied URL, timeout or invalid response can produce fallback content or a placeholder. Other widgets may still publish, and the Action can report the failed URL. See [health monitoring](/pro/health-monitoring).

An inlined counter cannot count each README visit, and links embedded within the SVG are not separate README controls. See [data sources and display limits](/reference/data-sources).
