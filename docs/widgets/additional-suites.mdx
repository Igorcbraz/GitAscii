These families are registered in the current SVG engine. See the [complete catalog](/widgets/overview) for every exact ID.

Each renderer has its own configuration reference and layout example in the sidebar. Start with [Premium ASCII Profile Card](/widgets/premium-ascii-profile-card), [Surveillance Header](/widgets/surveillance-header), [Windows XP Window](/widgets/winxp-window), [Minecraft HUD](/widgets/minecraft-hud), or [GitFut Card](/widgets/gitfut-card). The first four include output generated from offline fixture data.

The `rugbedbugg`, `windows_xp`, `andreicsantana`, and `minecraft` presets provide starting layouts for several of these families. Their display names and IDs are listed in [templates](/templates/overview).

## Data and fallback caveats

Decorative status labels, coordinates, roles and locations can have preset or renderer defaults. Replace them with accurate copy before publishing. A field named “telemetry” in a themed widget is not the Pro publication-health service.

The full SVG render path currently drops some optional enriched analytics fields during normalization. Premium ASCII scores, DNA and velocity may therefore use fallback-derived values. These visuals are not independently verified assessments of developer productivity. Read [data sources](/reference/data-sources) before interpreting them as metrics.
