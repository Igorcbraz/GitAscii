The current engine registers **82 widget IDs plus the `terminal-card` compatibility alias**. Each receives a widget configuration, normalized GitHub data and global styles, then returns SVG markup. The backend or Action composes that markup and processes external assets before publication.

Start with [data sources and display limits](/reference/data-sources): some values are illustrative or derived, and editor interactions do not become interactive controls in a README image.

## Common configuration

Widgets use the [WidgetInstance model](/api/configuration) for position, size, visibility and `zIndex`. The shared wrapper reads frame colors, radius, `hideBorder`, `hideDecorations`, and entrance-animation settings. Renderers with their own frames can handle styling differently; an arbitrary property is not supported merely because `WidgetConfig` accepts string keys.

| Property                                         | Shared wrapper behavior                     |
| :----------------------------------------------- | :------------------------------------------ |
| `backgroundColor`, `borderColor`, `borderRadius` | Frame styling, with global-style fallbacks. |
| `hideBorder`                                     | Removes the wrapper's border.               |
| `hideDecorations`                                | Suppresses wrapper template decorations.    |
| `animationType`                                  | Entrance effect; default `none`.            |
| `animationDuration`                              | Duration in milliseconds; default `1500`.   |
| `animationDelay`                                 | Delay in milliseconds; default `0`.         |
| `animationEasing`                                | Timing function; default `ease-out`.        |

See [animations](/reference/animations) and [custom widget development](/guides/custom-widgets). Code fragments in individual widget pages assume the GitAscii repository environment and preexisting `profileData`/`globalStyles`; use the [executable example](/guides/reproduce-editor) for a complete standalone image.
