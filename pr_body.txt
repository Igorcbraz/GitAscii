## Description
This PR introduces the new Strobi Mascot (our Disney-Grade scroll journey interactive companion) to the landing page and editor.

### Changes Included
- Added Strobi Mascot core logic and animation state machine.
- Integrated Strobi into the landing page to act as a navigational assistant.
- Implemented the StrobiRoot and StrobiProvider at the layout level.
- **Fix:** Optimized getAppInstallations to use concurrent Promise.all for paginated fetches instead of sequential fetching.
- **Fix:** Optimized fetchUserGitAscii inside getStoredProfiles to run profile lookup promises concurrently. This drastically reduces the time taken to fetch metrics and resolves the 60-second build timeout that was causing the CI to fail on the / page.

### Notes
A separate issue will be created to track the improvement of Strobi's suggestions in the editor and integration with the onboarding flow.
